# オセロ

## どんなプログラムか
- ターミナルで遊べるオセロです。
- 現在は人vs人、人vsAI、AIvsAIで遊ぶことができます。
- AIの種類はランダムAI、貪欲法AI、評価表AIがあります。
- ランダムAI：置ける場所からランダムに選ぶ
- 貪欲法AI：一番多く石を裏返せる場所を選ぶ
- 評価表AI：マスごとに点数（角は高い、角の隣は低い）をつけて、点数が高い場所を選ぶ


## 遊び方
- ターミナル（powershellなど）上で遊びます。
- pythonのバージョンは3.11.7で開発しています。また、外部ライブラリは不要です。
- `python main.py`で実行できます。
- 座標を「行 列」の順番で入力することで駒を置くことができ、一般的なルールで行います。
- 起動時に対戦モードとAIの種類を選べます

## AIの強さの比較
AI同士を100局ずつ対戦させる試行を5回行い、勝率の平均をとりました（`python compare.py` で実行できます）。
先手・後手の有利不利を除くため、黒と白を入れ替えた対戦も行っています。

| 対戦 | 強いほうが白のとき | 強いほうが黒のとき |
|---|---:|---:|
| 貪欲法 vs ランダム | 60.4% | 60.4% |
| 評価表 vs ランダム | 83.0% | 78.2% |
| 評価表 vs 貪欲法 | 81.2% | 80.0% |

### 分かったこと
- 強さは「評価表 > 貪欲法 > ランダム」の順になりました。
- 黒と白を入れ替えても強いほうが勝ち越しており、手番の有利不利ではなくAIの強さの差だと言えます。
- 貪欲法はランダムに約6割しか勝てませんでした。目先の枚数を多く取っても、角を取られやすく、有利になりにくいためと考えられます。
- 評価表AIは貪欲法にも約8割勝ちました。オセロでは「何枚取るか」より「どこに置くか」が重要だと分かります。

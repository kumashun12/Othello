# オセロ

## どんなプログラムか
- ターミナルで遊べるオセロです。
- 人vs人、人vsAI、AIvsAIで遊ぶことができます。
- AIは次の7種類があります。

| AI | 先読み | 手の選び方 |
|---|---|---|
| ランダム | なし | 置ける場所からランダムに選ぶ |
| 貪欲法 | なし | 一番多く石を裏返せる場所を選ぶ |
| 評価表 | なし | 置くマスの点数（角は高く、角の隣は低い）が一番高い場所を選ぶ |
| 1手読み（石の数） | 1手 | 打ったあとの「自分の石の数 − 相手の石の数」が最大になる手を選ぶ |
| 2手読み（石の数） | 2手 | 相手が最善手を打つと仮定して、2手先の石の数の差が最大になる手を選ぶ（ミニマックス法） |
| 1手読み（位置） | 1手 | 打ったあとの盤面全体を評価表で採点し、最大になる手を選ぶ |
| 2手読み（位置） | 2手 | 盤面全体を評価表で採点し、2手先まで読んで選ぶ（ミニマックス法） |

## 遊び方
- ターミナル（PowerShellなど）上で遊びます。
- Pythonのバージョンは3.11.7で開発しています。外部ライブラリは不要です。
- `python main.py` で実行できます。
- 起動時に対戦モードとAIの種類を選べます。
- 座標を「行 列」の順番で入力すると、石を置くことができます。ルールは一般的なオセロと同じです。

## AIの強さの比較
AI同士を100局ずつ対戦させる試行を5回行い、勝率の平均をとりました（`python compare.py` で実行できます）。
先手・後手の有利不利を除くため、黒と白を入れ替えた対戦も行っています。

| 対戦 | 強いほうが白のとき | 強いほうが黒のとき |
|---|---:|---:|
| 貪欲法 vs ランダム | 61.6% | 60.2% |
| 評価表 vs ランダム | 82.0% | 74.4% |
| 評価表 vs 貪欲法 | 80.2% | 81.4% |
| 2手読み（石の数） vs 1手読み（石の数） | 66.2% | 71.0% |
| 評価表 vs 1手読み（石の数） | 83.6% | 80.2% |
| 評価表 vs 2手読み（石の数） | 71.4% | 72.4% |
| 1手読み（位置） vs 1手読み（石の数） | 86.0% | 87.0% |
| 2手読み（位置） vs 2手読み（石の数） | 79.4% | 79.8% |
| 2手読み（位置） vs 1手読み（位置） | 87.4% | 88.8% |
| **2手読み（位置） vs 評価表** | **85.8%** | **77.4%** |

### 分かったこと
- 一番強いのは「2手読み（位置）」で、それまで最強だった評価表AIにも約8割勝ちました。
- 黒と白を入れ替えても強いほうが勝ち越しており、手番の有利不利ではなくAIの強さの差だと言えます。
- **評価のしかたが最も重要でした。** 先読みの深さが同じでも、石の数ではなく位置で評価したAIが約8〜9割勝ちました。
- 石の数で評価する2手読みAIは、先読みをしない評価表AIに約7割負けました。評価のしかたがずれていると、先を読んでも強くなりにくいと考えられます。
- **先読みの効果は、評価が良いほど大きくなりました。** 2手読みの1手読みに対する勝率は、石の数で評価した場合は約7割でしたが、位置で評価した場合は約9割でした。
- 貪欲法はランダムに約6割しか勝てませんでした。目先の枚数を多く取っても、角を取られやすく、有利になりにくいためと考えられます。

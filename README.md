# オセロ

## どんなプログラムか
- ターミナルで遊べるオセロです。
- 現在は人vs人、人vsAI、AIvsAIで遊ぶことができます。
- AIの種類はランダムAI、貪欲法AI、評価表AIがあります。
- ランダムAI：置ける場所からランダムに選ぶ
- 貪欲法AI：一番多く石を裏返せる場所を選ぶ
- 評価表AI：マスごとに点数（角は高い、角の隣は低い）をつけて、点数が高い場所を選ぶ


## 遊び方
- ターミナル（powershellなど）上で遊びます。
- pythonのバージョンは3.11.7で開発しています。また、外部ライブラリは不要です。
- `python main.py`で実行できます。
- 座標を「行 列」の順番で入力することで駒を置くことができ、一般的なルールで行います。
- 対戦モードはmain.pyを編集して切り替えます。
- `python compare.py`でそれぞれのAI同士での勝率を見ることができます。

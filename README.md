# オセロ

## どんなプログラムか
- ターミナルで遊べるオセロです。
- 人vs人、人vsAI、AIvsAIで遊ぶことができます。
- AIは次の10種類があります。

| AI | 先読み | 手の選び方 |
|---|---|---|
| ランダム | なし | 置ける場所からランダムに選ぶ |
| 貪欲法 | なし | 一番多く石を裏返せる場所を選ぶ |
| 評価表 | なし | 置くマスの点数（角は高く、角の隣は低い）が一番高い場所を選ぶ |
| 1手読み（石の数） | 1手 | 打ったあとの「自分の石の数 − 相手の石の数」が最大になる手を選ぶ |
| 2手読み（石の数） | 2手 | 相手が最善手を打つと仮定して、2手先の石の数の差が最大になる手を選ぶ |
| 1手読み（位置） | 1手 | 打ったあとの盤面全体を評価表で採点し、最大になる手を選ぶ |
| 2手読み（位置） | 2手 | 盤面全体を評価表で採点し、2手先まで読んで選ぶ |
| ミニマックス（深さ2〜4） | 2〜4手 | 再帰を使ったミニマックス法。指定した深さまで読み、盤面全体を評価表で採点して選ぶ |

※ ミニマックス（深さ2）は、2手読み（位置）と同じ考え方を再帰で書き直したものです。

## セットアップ
### 必要なもの
- Python 3.11以上（3.11.7で開発・動作確認済み）
- Git
- 外部ライブラリは不要です
- Windowsで動作確認しています

### 手順
※ 以降の操作はターミナル（PowerShellなど）で行ってください。

1. リポジトリをクローンします。
```
git clone https://github.com/kumashun12/othello.git
cd othello
```

2. Pythonのバージョンを確認します。
```
python --version
```
`Python 3.11.x` 以上が表示されればOKです。

3. 実行します。
```
python main.py      # 対戦する
python compare.py   # AI同士の勝率を比較する
```

### うまく動かない場合
開発中、Windowsで `python --version` を実行すると `Python` とだけ表示され、実行できないことがありました。
そのときは `py --version` では実行できたため、`py` で仮想環境を作り、有効にしてから `python` で実行しました。

```
py -m venv .venv
.venv\Scripts\activate
python main.py
```

原因としては、Windowsの「アプリ実行エイリアス」が有効になっていたことや、Pythonのインストール時に「Add python.exe to PATH」にチェックを入れていなかったことが考えられます。詳しくは [Python公式サイト](https://www.python.org/) を参考にしてください。

### 仮想環境について
外部ライブラリを使っていないため、仮想環境は必須ではありません。外部ライブラリを使って改造する場合は、仮想環境を作っておくことをおすすめします。

```
python -m venv .venv
.venv\Scripts\activate
```

## 遊び方
- `python main.py` で起動します。
- 起動時に対戦モードとAIの種類を選べます。
- 座標を「行 列」の順番で入力すると、石を置くことができます（例：`3 4`）。
- ルールは一般的なオセロと同じです。

## AIの強さの比較
AI同士を100局ずつ対戦させる試行を5回行い、勝率の平均をとりました（`python compare.py` で実行できます）。
先手・後手の有利不利を除くため、黒と白を入れ替えた対戦も行っています。

### 先読みなし〜2手読みのAI
| 対戦 | 強いほうが白のとき | 強いほうが黒のとき |
|---|---:|---:|
| 貪欲法 vs ランダム | 61.6% | 60.2% |
| 評価表 vs ランダム | 82.0% | 74.4% |
| 評価表 vs 貪欲法 | 80.2% | 81.4% |
| 2手読み（石の数） vs 1手読み（石の数） | 66.2% | 71.0% |
| 評価表 vs 1手読み（石の数） | 83.6% | 80.2% |
| 評価表 vs 2手読み（石の数） | 71.4% | 72.4% |
| 1手読み（位置） vs 1手読み（石の数） | 86.0% | 87.0% |
| 2手読み（位置） vs 2手読み（石の数） | 79.4% | 79.8% |
| 2手読み（位置） vs 1手読み（位置） | 87.4% | 88.8% |
| 2手読み（位置） vs 評価表 | 85.8% | 77.4% |

### ミニマックス法（深さ別）vs 評価表
| ミニマックスの深さ | ミニマックスが白のとき | ミニマックスが黒のとき |
|---|---:|---:|
| 深さ2 | 84.2% | 82.2% |
| 深さ3 | 91.0% | 87.8% |
| **深さ4** | **92%** | **91%** |

※ 深さ4は1局に約10秒以上かかるため、100局×1回で測定しています。

### 分かったこと
- **一番強いのはミニマックス法（深さ4）**で、評価表AIに黒白どちらでも9割以上勝ちました。
- **深く読むほど強くなりました。** 評価表AIに対する勝率は、深さ2 → 3 → 4 と上がりました。一方で、深さを1つ増やすたびに計算時間も大きく増え、強さと速さはトレードオフの関係にあります。
- **評価のしかたが最も重要でした。** 先読みの深さが同じでも、石の数ではなく位置で評価したAIが約8〜9割勝ちました。
- 石の数で評価する2手読みAIは、先読みをしない評価表AIに約7割負けました。評価のしかたがずれていると、先を読んでも強くなりにくいと考えられます。
- **先読みの効果は、評価が良いほど大きくなりました。** 2手読みの1手読みに対する勝率は、石の数で評価した場合は約7割でしたが、位置で評価した場合は約9割でした。
- 黒と白を入れ替えても強いほうが勝ち越しており、手番の有利不利ではなくAIの強さの差だと言えます。
- 貪欲法はランダムに約6割しか勝てませんでした。目先の枚数を多く取っても、角を取られやすく、有利になりにくいためと考えられます。

### 分からなかったこと（今後の課題）
- ミニマックス法同士（深さ3 vs 2、深さ4 vs 3）を戦わせると、深さによる差がはっきり出ませんでした。ミニマックス法は同点の手が少なく、ほぼ毎回同じ手を選ぶため、試合のパターンが少なくなっている可能性があります。

## 今後の予定
- 最初の数手をランダムにして試合のバリエーションを増やし、ミニマックス法同士の深さの差を調べる
- αβ法で探索を速くし、より深く読めるようにする
- 終盤は残りのマスが少ないため、最後まで読み切る（完全読み）
- 「1手読み（位置）」と「評価表」を比べ、盤面全体を評価する効果を確かめる
